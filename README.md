# ALLMart

ALLMart는 디지털 소외계층을 위한 음성 주문 시스템으로, 모놀리식 기반에서 시작해 Kafka 이벤트 기반 비동기 아키텍처 및 MSA 구조로의 전환을 준비한 프로젝트입니다.
